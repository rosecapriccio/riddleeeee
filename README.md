# 🧩 謎解きアドベンチャーゲーム「riddleeeee」

ブラウザで手軽に挑戦できる、シングルページアプリケーション（SPA）構成の本格的な謎解きゲームです。
洗練されたユーザー体験（UX）と、データ分析に基づいた難易度設計を意識して開発しました。

👉 **[今すぐ謎解きに挑戦する（公開URL）](https://rosecapriccio.github.io/riddleeeee/)**

---

## 🎮 ゲーム概要

、全5問で構成された謎解きゲームです。

- **ボリューム**: 全5問（想定所要時間：10〜20分）
- **解答システム**: 「ひらがな」入力によるリアルタイム判定
- **3段階のヒント機能**: プレイヤーの進行状況に合わせて、段階的に解放されるヒントを各問題に用意。

### 1. ユーザーを特定しない匿名データ分析（GA4連携）
`react-ga4` を導入し、各問題の「クリアに要した時間」や「ヒントの使用率」を、Cookieを用いた個人を特定しない完全な匿名形式で収集しています。
これにより、**「どの問題が難しすぎるか」「どこで離脱が起きているか」をデータに基づいて可視化・分析**し、ゲームの難易度調整やUX改善に活かすという、実務のサービス運用に即したデータドリブンな設計を取り入れています。

### 3. レスポンシブ＆マルチデバイス対応
PCのブラウザ環境はもちろん、スマートフォンやタブレットの画面サイズでもデザインが崩れず、キーボード入力やタップ操作が快適に行えるよう、CSSを用いた完全レスポンシブなUI設計を徹底しています。
